# 📱 Mobile Sales Dashboard – Power BI

## 📌 Project Overview

An interactive Mobile Sales Dashboard developed using Microsoft Power BI to analyze mobile sales performance, customer behavior, and generate meaningful business insights.

## 🖼️ Dashboard Preview

![Mobile Sales Dashboard](Screenshot%202026-11-07%20190440.png)

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📊 Dashboard Highlights

- Total Sales and Quantity Analysis
- Monthly Sales and Quantity Trends
- City-wise Sales Performance
- Brand and Mobile Model Analysis
- Customer Ratings Analysis
- Transactions by Payment Method
- Interactive Filters and Slicers

## 🚀 How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the interactive dashboard.
4. Apply filters to discover business insights.
